# EV Charge Advisor CH

Информационная система управления данными зарядной инфраструктуры электромобилей Швейцарии с интеграцией метеорологических данных.

Система собирает открытые данные о зарядных станциях, их статусах и погоде, ведёт хранилище со слоями raw → staging → core → mart, контролирует качество и происхождение данных, прогнозирует загрузку сети и помогает водителю выбрать станцию: с подходящим разъёмом, нужной мощностью и высокой вероятностью свободной точки к моменту приезда.

Проект общий для трёх работ (РТУ МИРЭА, ИНБО-20-23, Бражкин А.А.):
- итоговый проект по дисциплине «Прогнозно-аналитические системы» (профиль «Управление данными»);
- курсовая работа по дисциплине ПСУД;
- выпускная квалификационная работа.

Проектное решение: [docs/DESIGN.md](docs/DESIGN.md). Предшественник: [evcharge-ch-forecast](https://github.com/yandhi2018/evcharge-ch-forecast) (сбор данных, сентябрь 2026).
